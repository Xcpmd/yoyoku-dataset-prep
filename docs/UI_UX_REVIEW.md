# Yoyoku Dataset Prep 用户界面评审

评审日期为 2026 年 11 月 25 日。以 7c188ed 为基线，检查了当时正在修改的前端工作树快照。使用 Windows 上的 Edge 渲染当前 React 界面，程序数据由测试替身提供，图片采用仓库测试样本。覆盖 360×560、390×600、768×650、1024×768 和 1440×900 的代表性页面状态。实际 Tauri 安装包、系统文件选择器、拖放和后台推理需按文末用例在发布版验收。

## P1 · 优先修复

### 1. 窄窗口裁掉整个工作区的右侧

**已复现。** 打开含 18 张图片、项目名较长的项目，切到图库并缩窗。390 像素窗口中的顶栏和工作区宽 452 像素，360 像素窗口中宽 442 像素。360 像素时最大化与关闭完全离开可视区，图库按钮和缩略图的右侧被裁。切到打标和导出，复现标注动作、审核按钮及导出头部按钮被裁。底部导航固定在窗口边缘，因此仍能切页。图库的同一场景在 768、1024 和 1440 像素下可显示三个窗口按钮。

**实现。** 先在应用外壳为唯一的外层网格列设置 minmax(0, 1fr)，检查主区和页面容器的最小宽度。只在浏览器评审中临时应用该列设置后，360 像素图库顶栏收至 360 像素，三个窗口按钮全部可点击。再针对各页处理内部横向溢出，给可收缩的标题、路径、控件组设置最小宽度及截断或换行规则。窗口控制保留固定空间。工作区的真实横向滚动限于文件树、代码预览等局部内容。

**验收。** 使用 36 字项目名、长中文与英文文件名，在 360、390、768、1024、1440 像素逐页检查。键盘聚焦窗口控制后页面没有横移，导入、打标审核、导出预检按钮可完整看见并点击。用大字体和 125% Windows 缩放再验一次。  
定位见 [外层网格](../src/styles/pages.css)、[窄窗覆盖样式](../src/styles/apple.css) 和 [项目外壳](../src/app/ProjectShell.tsx)。

### 2. 窄窗任务中心缺少返回入口

**已复现。** 有导入任务运行时，768 像素图库顶栏显示任务入口。到 390 和 360 像素时入口被隐藏，底部导航只有导入、裁剪、打标、导出。导入提交后会自动打开任务抽屉，用户收起后，图库缺少能直接重新打开的可见入口。命令面板以及导出运行区已有入口，各自适用于对应操作路径。

**实现。** 把提示词库、质量检查等次级入口放进窄窗的「更多」，为任务保留独立入口或把「更多」设置为常驻入口并在其上显示运行状态。复用现有任务抽屉。状态显示用「2 项任务进行中」「1 项任务失败」等可读文案，完成后还能进入历史。导入成功提示增加「查看任务」快捷动作。批量打标若仍在工作台内执行，展示它实际所在的进度入口。

**验收。** 360、390 像素下启动导入，收起抽屉，切换页面，再通过可见入口打开任务和暂停、取消或重试按钮。用键盘同样能够到达，收起抽屉后焦点返回入口。  
定位见 [顶栏与命令面板](../src/app/ProjectShell.tsx)、[窄窗隐藏规则](../src/styles/apple.css) 和 [任务抽屉](../src/app/JobsDrawer.tsx)。

### 3. 导入弹窗修改选项后，取消和正文空间同时被挤压

**已复现。** 打开导入弹窗，选择两张长文件名图片，等自动扫描完成，再切换「包含子目录」。在 360×560 下，底栏同时显示「取消」「重新扫描」「开始导入 · 2」，其中「取消」左侧越界 21 像素。底栏由 110 像素增至 279 像素，可滚动正文只剩 132 像素。长路径还使正文出现横向滚动。Esc 可以关闭空闲弹窗，并把焦点还给导入按钮。

**实现。**

- 弹窗页脚固定为「取消」和一个主动作。无可用扫描结果时显示「扫描文件」或「重新扫描」。结果可用时切换为「导入 N 张」。扫描中显示「正在扫描…」，提交中显示「正在加入队列…」。扫描失效的原因贴近主动作，避免在扫描结果末尾另放一条说明。
- 源文件是否会变化的说明放在「文件处理」字段旁。选中路径优先显示文件名或「已选 N 张」，展开后查看完整路径。路径标签限制在容器内，保留可点的移除按钮。文件来源用「已选来源」，兼容文件与文件夹。
- 把选项按实际依赖处理。路径、子目录和配套标注优先级会改变扫描结果。分组当前已在启动导入时传入，保持修改后可直接导入。若性能改造将复制方式或重复策略迁到导入阶段，同步更新后端和扫描失效规则。根据当前接口核对行为后再调整，避免提交时使用旧选项。
- 并发扫描只接纳最后一次请求对应的结果。关闭或重开弹窗后，旧请求完成也不能回填到新会话。明确「再次打开时恢复上次来源」或「开始新的导入」，根据交互设计给清空入口或匹配的初始状态。扫描取消可沿用当前导入任务的后端能力，关闭、取消和 Esc 使用一致语义。
- 源很多时显示总数和有上限的局部预览。后端当前最多返回 300 条预览，大批量时把「显示全部」改为「展开 N 条预览」，并提示完整异常报告的入口。按导入性能方案接续后端分页或报告，避免 UI 把预览条数说成扫描总数。

**验收。** 测试单张图、长路径、上千文件、扫描后改递归、换组、全不支持、扫描失败。360×560 下主动作与取消完整可见，正文只有纵向滚动。换组不重扫，旧扫描结果不会覆盖新结果。  
定位见 [导入弹窗](../src/features/library/ImportDialog.tsx)、[共用弹窗样式](../src/styles/components.css)、[导入命令](../src-tauri/src/commands.rs) 和 [扫描预览](../src-tauri/src/project/import.rs)。

### 4. 窄窗打标能看到批量按钮，却找不到选图工具

**已复现。** 360 像素下从「打标」切到工作台的「图片」，可看到「0 张」及停用的「批量打标」，素材栏已隐藏。同一工作台在 1024 像素时显示素材栏。当前批量打标和图库分别维护选区，在工作台内应明确选区来源。

**实现。** 在批量栏和窄窗工具栏保留「选图片」入口，复用素材栏的列表、键盘选中与工作台选区。窄窗以抽屉或单独栏呈现，打开列表用于多选时保持当前预览。显示「已选 N 张」「清空」和「批量打标」，未选时用「选图片」引导。把默认视图所在的「图片／打标／标注」改成内容名，建议用「图片／统计与词库／标注」，实现前核对各栏真实内容。正在打标时保留文字进度，显示已完成、失败和可处理的后续动作。

**验收。** 360、390 和 768 像素下，无需先放大窗口，即可选择两张图片再开始批量打标。关闭和再次打开选图面板后保留选区，切换到单图标注时看得到所选范围。  
定位见 [工作台选区、素材栏和批量栏](../src/features/editor/WorkbenchPage.tsx) 和 [素材栏响应式样式](../src/styles/apple.css)。

### 5. 标签统计的自动保存可能触发全项目删除

**源码确认，需用测试项目复验。** 没有勾选图片时，统计默认作用于全项目。编辑某条标签、清空文本后再点别处，当前的失焦保存会调用删除。界面把「清空后保存即删除」放在编辑按钮提示里，关闭输入框的动作容易被理解成离开编辑。  

**实现。** 空文本时保留输入并提示「请输入新标签」，或直接退出并保留旧值。把删除放到显式的「删除标签」动作。执行改名或删除前，把统计范围和受影响数量放在按钮旁，分别显示「修改已选 N 张」或「从 N 张图片删除」。提交时使用用户刚确认的范围，复用撤销能力。核对「当前图片」「选中图片」「全部图片」三种入口的按钮与请求范围一致。

**验收。** 没有选区时清空输入、点外部、按 Esc、按 Enter，都不会删除标签。显式确认后只改指定范围，撤销可恢复，失败时保留已有标签并给出反馈。  
定位见 [TagAssist 行内编辑与统计范围](../src/features/editor/TagAssist.tsx) 和 [批量请求类型](../src/lib/types.ts)。

## 合入后的施工验收

- 窗口缩到 360×560 和 390×600，走完「打开项目 → 导入 → 裁剪 → 打标 → 预检」。再以 768、1024 和 1440 像素检查侧栏与底部导航切换。核对长路径、长项目名及超大数量。
- 导入状态分别检查未选、扫描中、结果有效、结果失效、无可导入项、队列提交中与失败。每个状态只有一个可识别的主动作，错误贴近可执行动作。
- 用键盘完成打开和关闭弹窗、选择下拉项、批量选图及切换导出步骤。检查 Tab、Shift+Tab、Esc 与关闭后焦点回到触发位置。对隐藏页面或抽屉的控件检查是否仍可误聚焦。
- 用浅色、深色、减少透明度、大字体和高对比度检查同一组页面。把液态玻璃集中在顶栏、底部导航和浮层等少量控件上。密集表单及图片卡保持稳定底色，进度和失败状态同时提供文本或图标。对照项目 [Apple 视觉参考](../public/apple/DESIGN.md)。
- 发布安装包使用真实项目复验窗口控制、系统文件选择器、拖放、任务恢复、批量打标和导出预检。大数据量验证引用现有 [性能与发布方案](IMPORT_PERFORMANCE_PLAN.md)，关注缩窗、滚动及任务进行中是否仍能交互。
