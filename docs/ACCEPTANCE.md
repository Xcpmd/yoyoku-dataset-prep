本轮发现并修复：

1. **画布切换后卡在「载入图片…」**：缓存图片可能先触发 `onLoad`，随后 effect 把布尔状态重置为 false，且不再有第二次 load。改为按「素材 id + loaded/failed」派生载入状态，切换裁剪 / 打标与缓存命中时均正常。
2. **打标页出现裁剪手柄与「裁剪草稿 / 未保存」**：打标页现在只传只读画布（`croppable=false`），第一页签显示「预览」，不再渲染裁剪框；头部保存状态只统计标注，草稿徽章只在裁剪页出现。
3. **手机宽度侧栏遮住「图片 / 标注」切换**：移除了 <640 px 下 `wb-side` 的 fixed 全屏覆盖，改为在 `wb-body` 内全宽 flex；同时隐藏头部冗余图标、压缩顶栏，手机端不再出现标题竖排与按钮被裁切。
4. **项目页「最近项目」与卡片不对齐**：为 `projects-content` / `recent-head` / `recent-grid` 补 `width: 100%` 与左对齐，标题、搜索框与卡片左边缘一致。
5. **打标页仍显示裁剪草稿徽章 / 未保存**：已按工作区拆分保存状态。

## 缺陷与修复（本轮验收发现）

1. **集合列表为空**：`collections::list` 将 `created_at` 与成员数 `count` 的列索引读反，单行反序列化失败后被 `filter_map` 静默丢弃。已修正索引，并改为向上传播行错误。修复后“精选素材（3）”正常显示。
2. **移动端设置页横向溢出**：390 px 下主题卡片被窗口裁切。已为窄屏设置卡片增加 `min-width: 0` 与卡片内横向滚动，并压缩主题卡片内边距。
3. **移动端图库检查器默认遮挡**：窄屏继承桌面端“检查器打开”状态，整屏盖住网格。已改为 <960 px 默认关闭，并在跨入窄屏时自动收起。
4. **集合批量预览缺少归属差异**：加入/移除集合时代表差异仍显示未变化的标注。已改为显示“集合：未加入 → 已加入「集合名」”等归属变化。
5. **恢复路径穿越测试**：新增 `restore_rejects_parent_traversal_archive`，验证 `../evil.txt` 归档被拒绝且不会写出目标目录。
